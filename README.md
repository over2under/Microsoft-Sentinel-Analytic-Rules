# Microsoft Sentinel Analytics Rules

This repository manages Microsoft Sentinel
Analytics Rules using GitHub CI/CD.

## Purpose
- Centralized management of detection rules
- Version control for KQL detections
- Automated deployment to Microsoft Sentinel
- Testing and approval before production deployment

## Branches
- dev: Development and testing
- test: Pre-production validation
- main: Production-approved rules

## Deployment
Microsoft Sentinel Repositories and GitHub Actions
are used to deploy Analytics Rules.
